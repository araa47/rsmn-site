# Voice demo samples

These are **pre-programmed** examples used by the website voice player:

| File | Assistant line |
| --- | --- |
| `awning.mp3` | Awning’s in. Let the rain throw its best shot. |
| `cinema.mp3` | Movie mode. Lights down, blinds shut, projector warming up. Popcorn is your department. |
| `lock.mp3` | Door’s locked. I checked twice, so you can stop patting your pocket. |
| `morning.mp3` | Morning. Blinds are up, lights are off, and the kettle has the floor. |
| `home.mp3` | Welcome back. Lights are waking up, AC’s on your side, and the door’s locked behind you. |

The current files are a generic macOS `Tara` Indian-English TTS sample, not a
celebrity clone. To replace them with PocketTTS, a licensed voice, or a Rocky
sample from the client's HA:

1. Generate the same three lines with a voice you have permission to use.
2. Export each as a mono MP3, ideally 24 kHz / 64 kbps.
3. Keep the same filenames in this folder. No site code changes are needed.

Do not clone a real person's voice without consent.
