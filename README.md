# RSMN — website

Static marketing site for **RSMN**, an automation and interior-technology consultancy
in Mumbai. Built for interior designers, architects and their clients.

**Live:** https://araa47.github.io/rsmn-site/

No build step. No frameworks, no external fonts, no CDN, no analytics, no cookies.
Everything is served from this repository.

## Files

- `index.html` — the full site
- `privacy.html` — privacy note
- `styles.css` — styles
- `site.js` — mobile menu, app tabs, scroll reveal
- `assets/` — mark and social preview
- `robots.txt`, `sitemap.xml` — crawler metadata

Published with GitHub Pages from the `main` branch.
